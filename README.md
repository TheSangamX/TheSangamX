## Featured Projects — `$ ls featured-projects/`

### 🎓 Student Marks Predictor

**A single ML model, served three ways.** One FastAPI backend deployed on AWS EC2 powers both a live Streamlit web app and a native Kotlin/Jetpack Compose Android app on Google Play — proving the same pipeline can serve web and mobile from one source of truth.

- 🌐 Live app → [thesangamx-student-marks-predictor.streamlit.app](https://thesangamx-student-marks-predictor.streamlit.app)
- ⚙️ REST API with Swagger/OpenAPI docs, running as a `systemd` service on EC2
- 📱 Android client — Kotlin, Jetpack Compose, Retrofit, Material 3

`Python` `FastAPI` `Scikit-learn` `Kotlin` `AWS EC2` `Streamlit`

<br/>

### 🛡️ NewsIntel

**Production-grade fake news detection**, not a classroom demo. TF-IDF + Passive Aggressive Classifier under the hood, with Google OAuth, a Supabase-backed history log, and a glassmorphic UI shipped to a live domain.

- 🌐 Live app → [newsintel.sangamgupta.in](https://newsintel.sangamgupta.in)
- 🔒 Google Authentication + Supabase PostgreSQL for verification history
- 🧪 NLP pipeline: cleaning → tokenization → stopword removal → Porter stemming → TF-IDF

`Python` `Flask` `NLP` `Scikit-learn` `Supabase`

<br/>

### 💳 Credit Risk Predictor

**A lending-risk model with numbers that hold up.** `HistGradientBoostingClassifier` trained and tuned to a custom 15% decision threshold, with full feature-importance transparency, wrapped in a real-time Streamlit interface.

- 📊 85.17% accuracy · 75.99% ROC-AUC · custom threshold tuned for imbalanced risk data
- 🔍 Top-20 feature importance breakdown surfaced directly in the app
- 💻 Real-time default-probability prediction from applicant financial data

`Python` `Scikit-learn` `Streamlit` `Joblib`

<br/>

### 💧 AquaSense AI

**A reservoir intelligence platform**, built for a hackathon and engineered like a product: multi-page Streamlit dashboard, dual ML models, and a risk engine addressing a real national problem — India's flood/drought monitoring gap.

- 🌐 Live app → [aquasenseai1.streamlit.app](https://aquasenseai1.streamlit.app)
- 🤖 Linear Regression + Random Forest, benchmarked side-by-side
- ⚠️ Automated flood/drought risk scoring with actionable recommendations

`Streamlit` `Plotly` `Scikit-learn` `Pandas`
